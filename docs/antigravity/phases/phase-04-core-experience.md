# Fase 04 — Implementación del núcleo narrativo

## Objetivo único

Implementar la estructura base, navegación, hero y mecanismo de valor aprobados, sin abordar aún el rediseño completo de casos y trayectoria.

## Dependencia

Fase 03 aprobada y autorización explícita para modificar el producto.

## Trabajo autorizado

1. Aplicar tokens base de forma incremental.
2. Integrar el logo o placeholder aprobado en navegación/identidad.
3. Implementar Navbar, Hero y Value Engine.
4. Establecer estructura y ritmo globales sin reescribir secciones futuras.
5. Mantener contenido existente accesible mientras las siguientes fases estén pendientes.
6. Validar mobile y desktop del bloque intervenido.

## Prohibido

- Rediseñar Selected Work, Experience o Credentials en esta fase.
- Reemplazar contenido factual aprobado.
- Añadir animaciones decorativas no especificadas.
- Eliminar secciones futuras para “limpiar” temporalmente la página.

## Entregable

`../deliverables/phase-04-core-experience.md` más cambios de producto registrados en `../CHANGELOG.md`.

## Criterios de aceptación

- El primer viewport comunica posición y diferencial en diez segundos.
- Existe un CTA primario claro.
- El mecanismo de valor se comprende sin párrafos extensos.
- Navegación, foco, teclado y reduced motion funcionan.
- No hay regresiones visibles en secciones no intervenidas.
- Lint/build y anchos objetivo del bloque pasan.

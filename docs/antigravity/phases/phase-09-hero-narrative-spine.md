# Fase 09 — Hero y columna vertebral narrativa

## Objetivo único

Demostrar una nueva dirección visual completa mediante Navbar, Hero y Narrative Spine. Esta fase debe cambiar la percepción del portfolio antes de tocar el resto.

## Alcance autorizado

- Hero.

- Orden/anchors mínimos en App.
- Copy de estas dos superficies.
- Estilos base estrictamente necesarios.

## Diseño requerido

### Navbar

- Marca y posicionamiento legibles.
- Menos enlaces: Trabajo, Experiencia, Enfoque y Contacto.
- Un CTA discreto.
- Logo presente sin parecer app icon.

### Hero desktop

- Portada editorial asimétrica.
- Headline dominante y más corto.
- Dos CTA como máximo.
- Logo usado como sello, marca de profundidad o composición lateral.
- Una franja compacta de prueba profesional.
- Sin panel rotativo, tabs o ventana tipo software.

### Hero mobile

- Posicionamiento, H1, bajada y CTA principal visibles dentro de la primera pantalla o muy cerca.
- Altura total objetivo: no más de aproximadamente 1,5 pantallas en 390 × 844.
- El logo no debe añadir una sección visual completa.

### Narrative Spine

- Apertura editorial: “Entre una buena idea y una ejecución real suele haber ambigüedad. Mi trabajo es reducirla.”
- Flujo conectado: Problem → Structure → Coordinate → Prototype → Validate → Iterate.
- No usar cinco/seis cards.
- Destacar el prototipo como artefacto que vuelve concreta la conversación.
- Mobile usa una línea vertical continua.

## Primera preview obligatoria

Cuando Hero + Narrative Spine compilen y ya representen esta nueva dirección:

1. Abrir la preview local.
2. Mostrar la primera versión antes de seguir puliendo.
3. Corregir sólo fallos de compilación o bloqueos visuales críticos.
4. No tocar otras secciones.

## Criterios de aceptación

- Se reconoce una nueva arquitectura a simple vista.
- El hero no parece una interfaz SaaS o dashboard.
- El posicionamiento se entiende en diez segundos.
- El Narrative Spine sustituye la repetición anterior.
- No se modificó ninguna sección fuera del alcance.
- Antigravity se detiene y no ejecuta Fase 10.

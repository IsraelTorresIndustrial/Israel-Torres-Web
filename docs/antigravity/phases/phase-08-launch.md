# Fase 08 — QA final y lanzamiento

## Objetivo único

Cerrar el proyecto con consistencia factual, visual y técnica, sin una ronda de rediseño tardía.

## Dependencia

Fase 07 aprobada.

## Trabajo autorizado

1. Releer el sitio completo contra North Star y fuente de verdad.
2. Confirmar que todas las decisiones P0 y P1 estén cerradas.
3. Revisar enlaces, contacto, metadata, favicon y recursos.
4. Comparar CV 2026 y portfolio si el CV está disponible.
5. Ejecutar build final y smoke test del sitio publicado.
6. Registrar URL, fecha, versión y pendientes P3.

## Prohibido

- Hacer cambios estructurales de último minuto.
- Introducir copy o métricas no revisadas.
- Publicar si queda un riesgo P0 abierto.

## Entregable

`../deliverables/phase-08-launch-report.md` con checklist final, URL publicada, verificaciones y backlog P3.

## Criterios de aceptación

- No existen riesgos P0 abiertos.
- La experiencia publicada coincide con la versión validada.
- La historia se entiende en las tres velocidades de lectura.
- Logo, contenido y metadata forman una identidad coherente.
- Todas las afirmaciones son defendibles y no sensibles.

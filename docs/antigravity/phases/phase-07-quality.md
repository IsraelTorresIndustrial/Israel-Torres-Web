# Fase 07 — Responsive, accesibilidad, performance y metadata

## Objetivo único

Validar y corregir la experiencia completa sin cambiar la narrativa aprobada.

## Dependencia

Fase 06 aprobada.

## Trabajo autorizado

1. Revisar 375, 390, 430, 768, 1024, 1280 y 1440+.
2. Corregir overflow, spacing, jerarquía, viudas, controles y densidad.
3. Auditar headings, landmarks, alt, ARIA, foco, teclado, diálogos y reduced motion.
4. Validar contraste y tamaño efectivo de texto.
5. Revisar LCP, CLS, fuentes, bundles, imágenes y carga diferida.
6. Completar title, description, canonical, Open Graph/X y favicon de marca.
7. Evaluar datos estructurados, sitemap y robots de acuerdo con la arquitectura final.
8. Ejecutar lint/build/tests y registrar resultados.

## Prohibido

- Reabrir decisiones de narrativa o marca por preferencias estéticas menores.
- Añadir features nuevas.
- Ocultar problemas de mobile eliminando contenido valioso.
- Optimizar métricas a costa de accesibilidad o comprensión.

## Entregable

`../deliverables/phase-07-quality-report.md` con matriz por viewport, accesibilidad, performance, metadata y verificaciones técnicas.

## Criterios de aceptación

- Ningún viewport objetivo presenta overflow o interacción inaccesible.
- La navegación completa funciona por teclado.
- No hay texto funcional ilegible ni contraste crítico.
- Animaciones respetan reduced motion.
- Metadata e identidad social coinciden con el posicionamiento.
- Build final pasa y los problemas conocidos quedan documentados.

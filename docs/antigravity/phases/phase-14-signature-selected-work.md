# Fase 14 — Teatro de Artefactos en Selected Work (Sistema Firma V3)

## Estado

**Activa y autorizada.**

## Objetivo único

Elevar **Selected Work (`Projects.tsx`)** al sistema visual firma V3 ("El Hilo Dorado"), transformando los capítulos de trabajo en un **teatro de artefactos tangibles** con escenografías diferenciadas (hojas editoriales, arquitectura de conocimiento y journey dinámico), eliminando ventanas genéricas de software y conectando el hilo dorado entre problema, intervención y entregable.

## Alcance autorizado

- `src/components/Projects.tsx`
- `src/data.ts` (si requiere ajustes en metadatos de los artefactos)
- `src/index.css` (estilos firma para artefactos superpuestos y conexiones)

## Dirección de diseño de artefactos

1. **Capítulo 01 — Presentation Intelligence (Hojas Editoriales Superpuestas):**
   - Composición de documentos/hojas en perspectiva sutil (Brief estructurado → Especificación de claims → Slide directivo vectorial editable).
   - Sin ventana con 3 dots genéricos. Estilo de hoja editorial de consultoría de alta dirección.
2. **Capítulo 02 — Market & Competitive Intelligence / RAG (Arquitectura de Conocimiento):**
   - Grafo/mapa de fuentes curadas (Tasas, Beneficios, Benchmarks 1:1) que convergen a través del Hilo Dorado hacia el copiloto con validación factual.
3. **Capítulo 03 — CRM & Customer Lifecycle (Journey de Activación & Coordinación):**
   - Flujo visual continuo de ciclo de vida conectado por el Hilo Dorado con momentos de activación y validación multiarea.
4. **Índice Secundario Compacto:**
   - Visualización minimalista y elegante de los proyectos secundarios (04, 05, 06) con expansión inline accesible.

## Criterios de aceptación

- Ningún caso principal depende de una ventana de software repetitiva.
- El Hilo Dorado conecta conceptualmente el problema con el artefacto.
- Máximo rendimiento sin librerías externas.
- Total accesibilidad y compatibilidad con `prefers-reduced-motion`.
- `npm run lint` y `npm run build` pasan con 0 errores.

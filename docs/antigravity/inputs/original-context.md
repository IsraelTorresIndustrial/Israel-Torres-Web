# 34. Forma de trabajar en Codex

NO hagas un rediseño masivo inmediatamente.

Trabajemos iterativamente.

## FASE 1 — AUDIT

Primero revisa todo el proyecto y entrega:

1. arquitectura actual;
2. stack;
3. componentes;
4. fortalezas;
5. problemas;
6. deuda técnica;
7. problemas UX;
8. problemas UI;
9. inconsistencias de contenido;
10. propuesta de mejora priorizada.

NO modifiques archivos todavía.

---

## FASE 2 — PLAN

Después generar un roadmap dividido en:

### P0 — Obligatorio
Errores, contradicciones, responsive, información incorrecta.

### P1 — Alto impacto
Hero, selected work, experience, MVP positioning.

### P2 — Mejora UX/UI
Design system, layouts, interactions.

### P3 — Nice to have
Detalles premium y polish.

Esperar mi aprobación.

---

## FASE 3 — IMPLEMENTACIÓN

Implementar por bloques.

Después de cada bloque:

- indicar archivos modificados;
- explicar brevemente qué cambió;
- correr build/lint/tests si existen;
- comprobar que no se rompieron otras secciones.

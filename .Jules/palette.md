## 2024-05-24 - [SPA Skip Links & Disclosure Widgets]
**Learning:** In React SPAs, simply linking an anchor (`href="#id"`) to an element is not enough for screen readers to properly shift focus; the target container must have `tabIndex={-1}` and outline-none to programmatically accept focus without acting like an interactive element. Additionally, expand/collapse buttons without `aria-controls` fail to associate with the content they reveal for assistive tech users.
**Action:** Always pair skip-links with `tabIndex={-1}` on main content areas, and explicitly link toggle buttons to their content using `aria-controls="[id]"`.
